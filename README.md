# Learning with PACE

**Learning with PACE** is a fun and interactive web application that brings NASA's PACE (Plankton, Aerosol, Cloud, ocean Ecosystem) satellite data into classrooms. Designed for the PACE in Classroom challenge, this project aims to bridge the gap between scientific research and education by helping students and teachers across different age groups (8-11, 12-16, 16+) understand ocean ecosystems, atmospheric processes, and climate change. Through engaging features like quizzes, interactive maps, and an AI chatbot, the app transforms complex Earth science data into an accessible and enjoyable learning experience.

---

## 🚀 Features

- **Reading Modules**: Age-tailored content (8-11, 12-16, 16+) covering PACE, phytoplankton, ocean color, and climate data, with clickable sections for easy navigation (e.g., "What is PACE?", "How PACE Studies Phytoplankton").
- **Quiz Page**: Interactive assessments with real-time feedback and scoring to test understanding of ocean ecosystems and PACE data (e.g., "Which is a primary producer in ocean ecosystems?").
- **Map Game-Based Learning**: A Leaflet-powered interactive map displaying Chlorophyll-a concentrations, Aerosol Optical Depth, and Remote Sensing Reflectance. Clicking on regions (e.g., red zones) reveals ecological insights, such as high chlorophyll levels indicating higher algae and lower marine life.
- **PACE Chatbot**: An externally integrated AI assistant that answers questions and supports users, enhancing personalized learning (e.g., "Welcome to Learning with PACE ★ Let’s embark on your PACE journey together").
- **Multimedia Integration**: Includes timelapses (e.g., "PACE Data Timelapse") and images (e.g., PACE satellite in assembly) to visualize scientific concepts dynamically.

---

## 🛠️ Technologies Used

- **Frontend**: 
  - **ReactJS**: For building a dynamic, single-page application with modular components.
  - **Leaflet**: For rendering interactive maps with NASA PACE data visualizations.
  - **Bootstrap**: For responsive, professional styling and layout design.
- **Data Source**: NASA PACE satellite data (Chlorophyll-a, Aerosol Optical Depth, Remote Sensing Reflectance).
- **AI Integration**: External chatbot for real-time user support.

## 📖 How It Works

1. **Learn**: Navigate reading modules tailored to your age group (8-11, 12-16, 16+) to explore PACE data and environmental science.
2. **Test**: Take quizzes with instant feedback to assess your knowledge (e.g., identifying phytoplankton as primary producers).
3. **Explore**: Interact with the map game, clicking regions to uncover data insights (e.g., red zones showing high algae levels).
4. **Ask**: Use the PACE Chatbot for on-demand answers and guidance throughout your learning journey.
5. **Visualize**: Watch timelapses and view images to see PACE data in action.

## 🚀 Installation and Setup

### Prerequisites

- **Node.js** (v14 or higher)
- **npm** or **yarn**

### Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/shrey416/learningPACE.git
   cd learningPACE/PACE
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Run the Application**:
   ```bash
   npm run dev
   ```
4. **Access the App**:
   go to ```http://localhost:5173/```
